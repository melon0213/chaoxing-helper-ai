超星学习通小助手 · 自定义 AI API版
制作日期：2026-10-06

这是在本对话之前导出的《超星学习通小助手 v4.0》上制作的独立修改版。
原文件没有被覆盖。此文件没有包含你的 API 密钥，也没有在你的浏览器中安装。

一、它能做什么

1. 支持文字单选题、多选题、判断题；根据 AI 返回的选项编号填写对应答案，并在运行日志中显示简短解释。
2. 支持两种运行方式：题库找不到答案时使用 AI；只使用 AI。
3. 支持自定义接口地址、API 密钥、模型名称、每页调用上限、等待时间。
4. 采用兼容 OpenAI 的 Chat Completions 接口格式。服务商提供这种格式即可尝试接入，具体模型可用性取决于你的服务商账号。
5. AI 默认为关闭，只有你配置并启用后才会发出请求。
6. AI 参与的测试会留在页面中，请你检查后手动保存或提交。它不会将“成功填入答案”视为“答案一定正确”。
7. 图片题、依赖图片的选项、填空题、简答题、论文题目前不支持。请手动处理这些题。

二、安装：复制到篡改猴的新增脚本页面

1. 用 Windows 记事本打开同文件夹内的“超星学习通小助手_AI自定义API版.user.js”。
2. 按 Ctrl+A 全选，再按 Ctrl+C 复制全部内容。
3. 在 Edge 的扩展菜单中打开“篡改猴”，进入“管理面板”。
4. 找到之前的“超星学习通小助手”，把它的启用开关关闭，避免两个版本同时操作同一个课程页面。
   只关闭，不必删除；之后可随时切回原版。
5. 在管理面板点击“+”（添加新脚本）。
6. 在脚本编辑器中按 Ctrl+A，按 Ctrl+V，用刚才复制的完整文件内容替换默认模板。
7. 按 Ctrl+S 保存。列表中会出现“超星学习通小助手 · 自定义 AI API版（本地修改）”。
8. 重新打开课程页面。需要时刷新整个课程页面，不只刷新里面的小窗口。

三、配置自己的 API

API 是脚本向 AI 服务商发送题目的通道。
你需要从服务商控制台或接口文档中找到三个信息；不需要将密钥发送给我。

1. 接口地址：优先填写完整的 Chat Completions 地址，例如服务商给出的、以 /chat/completions 结尾的地址。
   如果服务商只给你 base URL（基础地址），可以填写以 /v1 或 /compatible-mode/v1 结尾的那个基础地址；脚本会补上 /chat/completions。
   不要填 API 管理网站、聊天网页或控制台的网页地址。
   非本机地址必须以 https:// 开头；本机中转可填 http://localhost:端口/v1。
2. 模型名称：必须填写服务商提供的准确模型标识，不能只填中文显示名称。
3. API 密钥：填写服务商给你的那串密钥，不包含前面的“Bearer ”字样。

配置入口有两个，任选一个：
· 课程脚本页面中的“自定义 AI API”区域 → “配置 AI API”；
· Edge 的篡改猴菜单 → 本脚本下的“配置 AI API”。

按照依次弹出的输入框填写：地址 → 模型 → 密钥 → 运行模式 → 调用上限 → 等待时间。
模式填写 0：关闭；1：题库查不到时使用 AI；2：只使用 AI。
每页调用上限默认 25 次，可以填写 1～100。
等待时间默认 90 秒，可以填写 10～180 秒。
全部填写成功才保存；中途取消不会保存这一轮修改。
已有密钥时，密钥输入框留空可沿用。配置完成后刷新课程页面。

密钥输入使用浏览器弹窗，不放进课程网页的文本框。
弹窗输入内容可见，录屏或旁人观看时注意遮挡。
密钥保存在此脚本的脚本管理器存储中，网页不显示完整密钥，日志不会输出它。
这种存储不是加密保险箱；导出包含脚本设置的备份或同步设置时，可能一起导出密钥，分享前请清除。
清除入口：篡改猴菜单 → “清除 AI 密钥并关闭”。然后刷新页面停止后续调用。

四、先测试连接，再运行题目

点击“测试连接（调用一次 API）”。它会发送一条 1+1 的小题，不读取你的课程答案。
出现“连接测试成功：AI 正确返回 B”，说明地址、密钥、模型及答案格式的基础验证通过。
测试也算一次 API 调用，可能产生费用。
测试连接不能保证所有真实题目都答对，或所有服务商都完全兼容。

脚本只发送题目、题型、选项及答题格式说明到你填写的 AI 接口。
AI 请求不包含学习通账号、密码、网页 Cookie、班级编号或课程编号。
原有题库请求和视频功能仍按原脚本运行；模式 2 的章节测试查题会跳过原题库。

五、遇到问题怎么办

“AI 功能未开启”：重新配置，将模式从 0 改为 1 或 2，然后刷新课程页面。
“API 密钥无效或已过期”：核对密钥、服务商账号及地址；不要在密钥前加 Bearer。
“API 地址或模型不存在”：核对完整请求地址及模型名称；控制台地址不是请求地址。
“API 限流或额度不足”：在服务商控制台检查限额及余额。此页面会暂停后续 AI 请求，避免连续失败调用。
“AI 请求超时”：检查网络，或把等待时间改大一些，然后刷新页面。
“未允许访问该接口域名”：检查脚本管理器弹出的访问许可，确认与自己填写的服务商域名一致。
“AI 返回格式不符合要求”：模型未按约定输出 JSON；可以重试或换用服务商支持的另一个模型。
“图片题请手动处理”：当前版本只做文字题，不会自动下载题图或发送给模型。
“本页调用上限”：本次页面达到你设置的调用次数。刷新页面会重新计数，但也可能再次产生费用。
“AI 答案未填写：页面选项无法完整对应”：网页结构可能与这个旧版脚本适配的结构不同，请反馈该题截图。

请把错误提示、接口地址和模型名称发来即可排查，不要提供账号密码、Cookie 或密钥。

六、检查范围与原脚本问题

已通过脚本语法检查和 19 项离线模拟测试；测试未发送付费 API 请求。
覆盖单选、多选、判断题解析；精确填写选项；旧多选答案清理；超时；401/429；调用上限；异步题目串题；原作业页面流程与 AI 人工提交保护。
尚未用你的真实服务商、密钥和登录后的学习通页面完成实际验证。

新版本修复了原查题异步回调共用题目变量的问题，并将缺失答案时随机选择的行为关闭。
“找到或填入答案的比例”不是真实正确率。旧版界面和计算容易让人误解，新版本已改名并修正比例计算。
新文件使用不同脚本名称和命名空间，所以原版设置不会自动复制。视频和题库等设置可按原来的选择重新配置。
